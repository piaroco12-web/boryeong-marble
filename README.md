# boryeong-marble
다 같이 돌자, 보령 한 바퀴 — 보령탐험대 체험 보드게임

금산판([geumsan-marble](https://github.com/piaroco12-web/geumsan-marble))과 같은 코드로 만든 보령판입니다. 게임 규칙·화면·미니게임 엔진은 그대로이고, `public/regions/boryeong/`의 데이터와 그림만 보령 것으로 바뀌었습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 배포용 파일
```

Vercel에 올릴 때는 Framework를 Vite로 두면 됩니다.

## 규칙 (금산판과 같음)

- 12턴, 하트 3개. 문제를 틀리거나 15초가 지나면 하트가 하나 줄어듭니다.
- 오늘의 도장 4곳(판마다 무작위)에서 문제를 맞혀 도장을 모으고 출발 칸으로 돌아오면 완주(+30점).
- 정답 +10점, 출발 칸을 지나면 +5점, 힌트 1번(틀린 보기 지우기), 보령 버스 3번(도장 장소로 바로 이동).
- 찬스 칸: 점수·버스표·하트·2칸 앞으로·깜짝 퀴즈·깜짝 미니게임 중 하나. 쉼터: 하트 1개 회복과 보령 이야기 카드.

## 보령판 구성

- 출발: 머드축제 마당 · 쉼터: 죽도 상화원 솔숲 · 찬스: 머드 보물 상자
- 장소 10곳: 보령머드테마파크, 대천해수욕장, 무창포 신비의 바닷길, 남포벼루 마을, 보령석탄박물관, 성주사지, 충청수영성, 천북 굴단지, 보령해저터널, 외연도 상록수림
- 안내 캐릭터: 보미, 령이 · 말: 머드 요정, 천북 굴돌이, 보령 대하, 등대 로봇

## 미니게임

`board.json`에서 장소의 `mode`가 `quiz_or_minigame`이면 절반 확률로 미니게임이 나옵니다. 성공하면 +15점과 도장, 실패해도 하트는 줄지 않습니다. 첫 화면의 **🎮 미니게임만 해 보기**로 따로 연습할 수 있습니다.

| 미니게임 | 장소 | 방식 |
|---|---|---|
| 갯벌에서 캐기 (`tidal`) | 대천해수욕장, 천북 굴단지 | 호미가 초록 칸에 올 때 캐기, 3번 성공 |
| 머드 짝 맞추기 (`memory`) | 보령머드테마파크 | 카드 8장 짝 찾기 (쉬움 45초 · 보통 32초) |
| 해저터널 뚫기 (`tunnel`) | 보령해저터널 | 화살표 명령을 순서대로 넣어 암반을 피해 원산도까지 (순차 명령, 기회 3번) |

## 퀴즈

저학년 31문항 · 고학년 30문항, 모두 61문항입니다. 분류는 `specialty` `history` `people` `nature` `environment` `society` `safety`.

문항을 더 넣거나 고칠 때 지킬 것:

- **`type: "choice"`의 `answer`는 항상 `0`** — 게임이 보기 순서를 매번 섞습니다(`src/main.js`의 `shuffle`). 정답을 첫 보기에 두면 됩니다.
- `type: "ox"`는 `choices`가 `["O","X"]`이고 순서를 섞지 않습니다. 참이면 `answer: 0`, 거짓이면 `1`.
- `places`는 `board.json`의 장소 키를 씁니다.
- 문항에 `"image": "photos/파일명.jpg"`를 더하면 문제 위에 사진이 나옵니다.

`verified: false`인 네 문항(H03, H16, H20, H25)은 보령시청·국가유산청 자료로 확인한 뒤 `true`로 바꿔 주세요.

첫 화면 왼쪽 아래 **⚙️ 선생님 설정**에서 바꿉니다. 설정은 그 기기 브라우저에만 저장됩니다.

| 항목 | 고를 수 있는 값 (기본값 굵게) |
|---|---|
| 턴 수 | 8 · **12** · 16 |
| 하트 | **3** · 5 |
| 문제 시간 | **15초** · 20초 · 30초 · 제한 없음 |
| 미니게임 | 끄기 · **보통**(절반) · 많이(80%) |
| 수업 시간 모드 | **끄기** · 15 · 20 · 30 · 40분 |

## 오프라인 설치

배포된 주소를 한 번 열면 게임 파일과 `board.json`에 적힌 그림을 기기에 저장합니다(`public/sw.js`). 그 뒤에는 인터넷이 없어도 실행되고, 크롬·엣지에서 "앱 설치"로 바탕화면에 둘 수 있습니다. 개발 서버(`npm run dev`)에서는 꺼져 있습니다.

저장 이름(`boryeong-marble-v1`), 설정 키(`boryeong-marble-settings`), 소리 설정 키(`boryeong-audio-enabled`)는 금산판·서천판과 겹치지 않게 지역 이름을 붙여 두었습니다. 같은 주소에 여러 지역판을 올려도 서로 설정을 덮어쓰지 않습니다.

### 화면 색을 보령답게 바꾸고 싶다면

`src/style.css`의 `:root` 색 토큰은 **의미가 묶여 있어** 손대지 않았습니다. `--berry`는 주 버튼·주사위·도장 색이고 377·459줄에 붉은 계열 그라데이션이 하드코딩으로 짝지어져 있으며, `--leaf`는 정답·성공 색입니다. 바꾸려면 아래를 함께 고쳐야 합니다.

| 고칠 곳 | 내용 |
|---|---|
| `:root` | `--ivory` `#d8c4a8` · `--rust` `#e4713a` · `--river` `#4fa3c7` · `--bg-deep` `#10303f` |
| `body` 배경 | `#6b4422` → `#1f5a73` |
| 377·459줄 | `#ef6c57`, `#f06e59` 를 `--berry`와 어울리는 색으로 |
| 51·387줄 | `#fff4d6`, `#c99a5a` 를 `--ivory`와 어울리는 색으로 |

`--berry`(주 강조)와 `--leaf`(정답)는 그대로 두는 쪽을 권합니다. 지역 느낌은 그림이 들어가면 충분히 살아납니다.
